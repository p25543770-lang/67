# Depth Studio

Веб-приложение для просмотра облака точек Kinect 360 (Kinect v1). Демо-сцена работает без датчика. Данные глубины отображаются как отдельный кадр, а не как сшитая 3D-модель помещения.

## Запуск демо

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite.

## Kinect 360

Нужны Kinect первого поколения, USB-адаптер с питанием, драйвер [libfreenect](https://github.com/OpenKinect/libfreenect), его Python-привязки и NumPy. Установите их согласно инструкции libfreenect для вашей ОС; убедитесь, что Python, которым запускается сервер, может импортировать `freenect` и `numpy`. На Linux также могут понадобиться правила udev и права доступа к USB. Kinect One не поддерживается.

Подключите датчик и в отдельном терминале запустите:

```bash
python3 server.py
```

Затем запустите `npm run dev`, откройте приложение на том же компьютере и нажмите «Подключить Kinect». Сервер слушает только localhost, а Vite проксирует `/api` к нему. Демо-предпросмотр на удалённом сервере не имеет доступа к Kinect, подключённому к вашему компьютеру: запускайте приложение локально. Глубина рассчитывается приближённо, без индивидуальной калибровки. Кнопка экспорта сохраняет видимые точки текущего кадра в ASCII PLY.

## Экспериментальное сканирование комнаты

На странице нажмите «Начать 3D-сканирование», медленно перемещайте Kinect, удерживая в поле зрения частично уже увиденные неподвижные поверхности. Затем нажмите «Остановить сканирование» и «Экспорт .PLY». Сервер совмещает соседние кадры методом ICP и накапливает облако точек; это **не** готовая полигональная модель. Пустые стены, быстрые повороты, движущиеся объекты и потеря перекрытия вызывают ошибки и дрейф. Цвет не захватывается. Для качественной реконструкции может понадобиться дополнительная обработка в CloudCompare или MeshLab.

Для сканирования дополнительно установите `numpy` и `open3d` в тот же Python: `python -m pip install numpy open3d`. Необходимо также установить совместимые с этим Python привязки libfreenect. Установка и доступность этих привязок на Windows зависят от сборки libfreenect; Kinect SDK сам по себе не заменяет модуль `freenect`. Это экспериментальное решение, не готовый установщик Windows и не гарантированно работающая конфигурация для любого драйвера. Проверьте `python -c "import freenect, numpy, open3d"` перед запуском.

На Windows после установки Node.js, Python, libfreenect и зависимостей можно запустить `start-windows.bat`. Откроются два служебных окна и браузер; для остановки закройте оба окна. Внешний USB-адаптер с питанием обязателен для большинства Kinect 360.

## Сборка Windows-приложения (.exe)

На Windows установите Node.js, затем выполните в папке проекта:

```bat
npm ci
npm run build:win
```

Готовый переносимый файл появится в `release` (сборка может занять несколько минут). Также сборка запускается в GitHub Actions по workflow **Build Windows application**: после успешного запуска скачайте артефакт `Depth-Studio-Windows` на странице запуска. Сборка не подписана цифровой подписью, поэтому Windows может показать предупреждение SmartScreen.

EXE содержит интерфейс и запускает локальный сервер, но **не содержит Python, Open3D и драйвер Kinect**. Для сканирования установите их отдельно, как описано выше, и добавьте `python` в PATH. Без них доступна только демонстрация. Установка Windows-совместимых привязок `freenect` может потребовать самостоятельной сборки; работа с конкретным датчиком не проверена.
